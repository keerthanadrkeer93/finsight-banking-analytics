# Data Dictionary

All data is **synthetic**, generated by `scripts/build_dataset.py` (seed 42). Star schema: `transactions` is the fact table.
Currency is INR. Dataset window: 2024-10-01 to 2026-09-30.

## transactions.csv (fact, one row per transaction attempt)
| Column | Description |
|---|---|
| transaction_id | Primary key (T000001...) |
| customer_id | FK to customers |
| product_id | FK to products |
| channel_id | FK to channels |
| txn_date | ISO date |
| txn_type | Purchase, Transfer, Bill Payment, Cash Withdrawal, EMI Payment |
| amount | Transaction amount (INR) |
| fee | Fee earned by the bank (INR). 0 for failed transactions |
| status | `success` or `failed` |
| failure_reason | Empty for successful rows. `Unspecified` where the source system did not record a reason |

## customers.csv
| Column | Description |
|---|---|
| customer_id | Primary key (C0001...) |
| region_id | FK to regions |
| segment | Value tier: Premium, High Value, Standard |
| signup_date | ISO date. Some customers pre-date the dataset window (existing base) |
| age_band | 18-24, 25-34, 35-44, 45-54, 55+, or `Unknown` |

## products.csv / regions.csv / channels.csv
Small lookup tables. `products.csv` also carries `fee_rate_pct` and `min_fee` (how fees were generated).

## Metric definitions
- **Revenue** = sum of `fee` on successful transactions
- **Success rate** = successful transactions / all transactions
- **Active customer** = at least one successful transaction in the period
